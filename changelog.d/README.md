# Changelog fragments

Each pull request adds its CHANGELOG entry as ONE file here, `changelog.d/<branch-name>.md`, written exactly as it
will appear under "### Unreleased" (a `####` heading and its text). Pull requests do not edit `CHANGELOG.md`
directly, so parallel pull requests never conflict on it. At release time the fragments are collected into
`CHANGELOG.md` (newest first) and deleted.
